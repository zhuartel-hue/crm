Klucze sklepu

Jak zdobyć klucze (5 minut)
  1. Zaloguj się do dev.shopify.com/dashboard tym samym kontem, co do sklepu.
  2. Apps → Create app → Start from Dev Dashboard, nazwa Sygnavo.
  3. W Versions: App URL zostaw domyślny, w Scopes wpisz read_orders,read_products,read_customers,read_inventory, kliknij Release.
  4. Install app → wybierz swój sklep → Install.
  5. W Settings skopiuj Client ID i Client secret i wklej tutaj.

Sygnavo ma tylko odczyt: nie zmieni nic w sklepie. Jeśli Shopify zgłosi „shop_not_permitted”, sklep jest w innej organizacji niż aplikacja: w Dev Dashboard przełącz organizację na tę, w której jest sklep.
