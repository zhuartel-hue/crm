# Dlaczego połączenia przeniesione z Firmao nie mają numerów?
Moduł: połączenia · Aktualizacja: 2026-11-26

Firmao nie udostępnia numerów telefonów ani klientów przy połączeniach przez swoje API. Przenosimy więc datę,
kierunek, wynik, czas rozmowy, osobę i powiązane zadanie. Klienta przypiszesz ręcznie, a nowe rozmowy zapisane
w Sygnavo z numerem łączą się z klientem same.
