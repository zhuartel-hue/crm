# Jak sprawdzać faktury kosztowe, zanim pójdą do księgowej?
Moduł: koszty · Aktualizacja: 2026-11-27

Każda nowa faktura kosztowa trafia do folderu **Koszty → Do weryfikacji**. Otwórz ją: po lewej jest podgląd faktury
z KSeF albo załączony skan, po prawej dane i kwoty. Kliknij **Zweryfikuj i dalej**, a program otworzy następną.
Sprawdzone są w folderze **Zweryfikowane**, wszystkie w **Wszystkie**. Fakturę spoza KSeF (papierową) dodasz
przyciskiem **Dodaj koszt** razem ze skanem.
